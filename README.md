# Noon Sales Performance Dashboard 📊

## Overview
This project presents an interactive **Power BI dashboard** analyzing **Noon’s sales performance** over time.  
The dashboard provides insights into sales trends, item performance, and salesperson contributions.

---

## 🔍 Key Insights
- **Total Sales Amount:** 627.01K  
- **Total Boxes Sold:** 843.45  
- **Average Selling Price:** 31.53  
- **Total Items:** 248  

### Visual Highlights:
- **Sum of Amount by Item Group:** Identifies top-selling categories such as "سوريال مي أند نا" and "سانتية".  
- **Sales Trend Over Time:** Displays monthly sales performance from March to August 2024.  
- **Sales by Salesperson:** Shows contribution percentages for each salesperson.  
- **Parent Item Group Distribution:** Breaks down items into local and imported categories.  
- **Top Performing Items:** Highlights the best-selling items by sales amount.

---

## 🧠 Purpose
The goal of this dashboard is to:
- Monitor sales performance trends over time.  
- Identify high-performing product categories and salespersons.  
- Support data-driven decision-making for inventory and marketing strategies.
